MYSTHIRU

收藏管理

直接管理画廊图片：上传新图、删除旧图，自动同步 gallery.html。

① 连接 GitHub

创建方法：GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
· Repository access 选 Only select repositories → mysthiru.github.io
· Permissions → Contents 选 Read and write
· Token 只保存在本浏览器 localStorage，访问本页的访客看不到你的操作记录（但请勿把页面 URL 外传）

② 上传图片

点击选择或拖入图片（支持 jpg / png / webp，自动压缩到 1200px 以内）

③ 当前收藏

连接后显示图片列表，悬停图片右上角可删除。
